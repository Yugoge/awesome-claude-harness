## Goal

1. **One disposition function for every stage.** `scripts/resolve-dev-artifact-chain.py --disposition --stage
   dev|close|commit` computes `chain_pass` or `incomplete` for one task. Strict pass is the only success (D2): every
   lane's BA-QA verdict is `pass` and its `qa.status` is `pass`. `pass_with_exceptions`, every reclassification and
   every disclosed exception are deleted, so the default mode's status is `pass` or `fail` too. The close stage adds a
   close-report whose last line is a `CLOSE: YES` form; the commit stage adds a `Task-id: <task>` commit reachable
   from HEAD in every repository of the task's commit plan. /close, /commit and the Stop gate (P5) consume this one
   result and never re-derive it (PLAN-v2 principle 1, TC-22).
2. **Facts-only gaps (D21).** Each gap names the artifact, the failing check's code and message, and the lane. No
   owner field, no fix text, no filename-to-role table in code or prose.
3. **Agent-writable releases retired.** The arbitration file and the arbitration and awaiting_input phases go;
   declare_awaiting_input is deleted; ESCALATION_ACK releases nothing. The disposition does not read escalation
   records: the artifact a record names is already a gap through the chain's own check (design ruling 3).
4. **No continuation include, no /redev binding (D21, D22).** /redev stays /dev minus re-emitting the spec
   (commands/redev.md unchanged). P4 and P5 consume the disposition and the declaring-dispatch reader (row 1).
5. **The S7 collection checks and the S8 fixes.** The canonical-aggregate barrier is scoped to the dispatch's own task
   and checks the aggregate's schema, identity and roster; gitignore-preflight exempts the close and commit producer
   profiles; G2 checks freshness and the lane/lane_set echo; the bare-/redev replay bug is fixed; codex enforcement
   skips close and commit producers. Every new blocking check ships warning-first (TC-40).
6. **Live landing.** Merged into a live home whose sessions keep running, nothing crashes on old state and nothing
   newly blocks a compliant in-flight cycle in the warning commits (owner, 2026-10-18; D15).
