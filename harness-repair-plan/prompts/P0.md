## Goal

Three independent fixes, each a few lines:

1. **No automatic push to a remote unless explicitly enabled (decision D1).** Today every dirty Stop
   pushes `refs/checkpoints/<branch>` to origin without reading `GIT_AUTO_PUSH`, which leaked private data
   to the public origin (255 refs already there; not your job to delete them).
2. **pytest collection stops aborting.** One test file calls `pytest.fail` at module level and kills
   collection for the whole suite.
3. **Slash commands stop re-sending their whole command file.** The UserPromptSubmit hook appends the
   full command spec (/dev about 108 KB, /close about 120 KB) to its output although the slash command
   already loads it.
