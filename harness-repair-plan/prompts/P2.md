## Goal

1. **Any repo.** Pipelines find harness scripts, the venv, policies and the todo scripts in the harness, and project
   files in the project, in any product repository, with CLAUDE_PROJECT_DIR unset (the Bash tool does not export it)
   and with the harness installed somewhere other than `~/.claude`. Prompts use the one harness-home channel P7
   shipped (TC-44): `${CLAUDE_HOME:-$HOME/.claude}`, the form every hook command in settings.json already uses. The
   permission entries that name harness paths move to the same spelling, so no command the allow list allows today
   starts asking (PR #4's technical-choices table: "P2 moves prompts and allows to the channel").
2. **Todo scripts and close-verdict load only from the harness.** A product repository's `scripts/todo/<cmd>.py` is
   never executed on prompt submit (D2.f, G-F11).
3. **/dev-overnight starts and ends.** It gets past Step 2 (the launcher publishes an empty contract today) and
   enforces end_time in every timezone (in UTC+8 there is no time-lock at all today), through one locator and one UTC
   parser in hooks/lib/overnight.py. The closeout is recomputed from disk (retro reports and the summary), with no
   clean-tree condition. The rendered cycle contract names the v2 schemas and no retry bound.
4. **S2 parking (D4b).** Inside the window, AskUserQuestion is denied to every caller of the overnight session, the
   main agent and its subagents, and to no other session (TC-45). The main agent is told to park the pipeline, a
   subagent to end with its producer-question artifact. The overnight summary carries a "Parked questions" section;
   after end_time each parked question is asked with AskUserQuestion, so the session waits for the owner inside a
   turn instead of looping on blocked Stops.
5. **Human release only (D4, S1).** The time-lock and the deny release on a human-typed `/stop` record in the
   session's own transcript, never on a state field or a token. /stop no longer backdates end_time.
6. **D6 landing.** No per-cycle commit. After the whole overnight session: `/close --auto`, `/commit --auto` (never
   `--bulk`), `/merge <worktree_branch>` (isolated modes only), `/push`, each typed by the owner (D6a), with where to
   type each one.
7. **Arm G1-G3.** The last commit sets CLAUDE_OBLIGATION_GATE, CLAUDE_OBLIGATION_STOPGATE and
   CLAUDE_OBLIGATION_BARRIER to `block` in the tracked settings.json. CLAUDE_OBLIGATION_TERMINAL is never added.
8. **Live landing.** Merged into a live home whose sessions keep running, nothing blocks a compliant in-flight cycle
   (owner, 2026-10-18; D15).
