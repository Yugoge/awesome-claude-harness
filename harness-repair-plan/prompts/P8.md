   unit and container names, the owner's home, workspace and multi-account paths, the SSH remote form, verbatim chat
   content. Private and incident records, strays and tracked runtime output are deleted; the files that stay are
   redacted; test fixtures become synthetic. The project's own public GitHub URL and the copyright line are the
   project's public identity and stay (landscape C3, "Legitimate identity"); the SSH remote form does not.
2. **One privacy engine (S6).** scripts/check-public-core.sh is the only detector. Its tracked rules are generic
   (`/root/...`, `/home/<user>`, `/Users/<User>`, an e-mail regex) plus P7's private-literal rule, which reads the

   The second and third detectors (scripts/detect-hardcoded-paths.sh, tests/ws2_zero_literal_gate.py) are gone, the
   checkpoint pre-push gate calls the engine, and no private literal is published inside the engine, its docs, its
   tests or its allowlist.
3. **Green, hermetic CI (F2.b, C4).** `.github/workflows/baseline.yml` is green on all three legs (3.10, 3.11, 3.12)
   on every push and pull request, weekly and on demand. Every test file present is collected, with no collect_ignore
   list and no quarantine (D17), so the tests later phases add (test_close_rating.py in P4, test_stop_command_gate.py
   in P5) join automatically and every later phase keeps CI green. Tests are hermetic: they pass as non-root and as
   root, with an empty HOME, on a read-only checkout, and never read or write the real home.
