# What the field does, and where it hurts (web research, 2026-11-09)

Searches run on 2026-11-09 for the owner's questions. Mostly vendor, practitioner and preprint sources; each line says
what its source claims, no more. Used by: `prompts/handoff/P12-L8.md` (the README's "Why this exists"),
`codex-review-loop.md` (D31) and `research/scoring-and-asking/P13-D32.md` (D32).

## 1. A person stays in the loop

- Practitioner guides keep developer review, testing and security review before merge, with agents closing the loop
  across the pre-merge stages; no primary source documents autonomous production deployment.
  https://www.augmentcode.com/guides/autonomous-engineering-loop
- CI plus PR review, with humans "on the loop" at review and merge.
  https://kilo.ai/articles/beyond-autocomplete
- In 37,623 agent-authored PRs, quality differs by vendor; Claude Code PRs waited a median 12.6 hours for a first human
  review. https://arxiv.org/pdf/2609.17598
- An argument (not an empirical study) that coding agents make human code review unnecessary, replaced by an automated
  verification pipeline on every candidate merge. https://arxiv.org/abs/2606.13175v1
- A practitioner who runs such a pipeline: the human work moves to specifying intent and accountability.
  https://blakecrosley.com/blog/agents-supersede-the-reviewer
- No reference architecture for a fully autonomous spec-to-merge pipeline was found.

## 2. Showcases rest on a human-built oracle; hype outruns code

- 16 parallel Claudes wrote a C compiler that builds the Linux kernel: about 2,000 sessions, two weeks, about $20,000.
  The author found test suites, wrote verifiers, used GCC as a known-good oracle, and added tests as mistakes showed.
  https://anthropic.com/engineering/building-c-compiler ;
  https://www.theregister.com/2026/02/09/claude_opus_46_compiler/ ;
  https://futurumgroup.com/insights/truth-or-dare-what-can-claude-agent-teams-and-developers-create-today/
- Cursor's agent-built browser (about 3 million lines): critics found recent commits that do not compile and failing CI
  on main. https://www.theregister.com/2026/01/22/cursor_ai_wrote_a_browser/ ;
  https://www.theregister.com/2026/01/26/cursor_opinion/ ; https://simonwillison.net/2026/Jan/19/

## 3. Instructions are not enforcement

- Hooks are the deterministic layer; a Stop hook can hold a turn until a check passes; prompt and agent hooks are not
  deterministic. https://code.claude.com/docs/en/best-practices
- CLAUDE.md is context, not enforced configuration; blocking needs a PreToolUse hook.
  https://towardsai.com/p/machine-learning/claude-code-skills-vs-subagents-vs-hooks-vs-workflows-which-to-use-in-2026
- Give the agent a verifiable exit condition; some teams add a second agent that tries to refute the result.
  https://www.openhands.dev/blog/claude-code-best-practices-agentic-coding
- One guide argues for starting with no hooks and adding small ones only when they earn their cost.
  https://claude-world.com/articles/hooks-development-guide/

## 4. AI reviewing AI loops on nits (D31)

- A reviewer-fixer cycle between bots never converges; their fix: no automatic hand-off on bot PRs, and escalation after
  a number of rounds. https://dev.to/zoetaka38/when-ai-reviews-ais-code-youve-built-an-infinite-loop-heres-how-we-stopped-it-4g1n
- Each full re-review surfaces new low-severity nits; proposed fix: re-reviews only validate earlier findings and report
  only new findings of medium or higher. https://github.com/fullsend-ai/agents/issues/1208
- Asking for a severity rating placed after the description, as JSON, filtered out most nitpicks.
  https://news.ycombinator.com/item?id=42451968
- Same-model self-review shows an agreeableness bias; only in-scope findings above a severity threshold should drive the
  fix loop. https://zylos.ai/research/2026-03-01-multi-model-ai-code-review-convergence/

## 5. Motivating agents, and scores with consequences (D32)

- EmotionPrompt (Li et al., 2023): emotional stimuli in the prompt improved results in the authors' experiments (8%
  relative on Instruction Induction, 115% on BIG-Bench; +10.9% in a 106-person human study). Larger models gain more;
  stacking stimuli adds little; positive words carry the effect. Follow-ups (EmotionAttack, NegativePrompt) show
  emotional wording can also hurt. 2023 models; replication on current models not checked.
  https://arxiv.org/abs/2307.11760 ; https://www.prompthub.us/blog/getting-emotional-with-llms
- Reputation should drive verification escalation, resource allocation and access, not only record history.
  https://arxiv.org/html/2605.00073v1
- Capability grants issued only above trust thresholds, short-lived and revocable.
  https://arxiv.org/html/2610.07000v1
- Reputation updated as a moving average of task performance, with penalties for observed failures.
  https://arxiv.org/pdf/2606.07940 ;
  https://www.sciencedirect.com/science/article/pii/S1568494626009075
- These are mostly conceptual or early-stage; their empirical results were not verified.
