(An /allow grant is the owner's single-use permission for one operation a grant-aware safety hook refused, and only the owner types it: `disable-model-invocation: true` and the `Skill(allow:*)` deny in `settings.json` keep the model from invoking it. When the owner types it, `hooks/userprompt-consent-allowlist.sh` writes or refuses the grant from the typed arguments and prints its notice, and the CLI delivers this body to the model as for any typed command; the body asks nothing of the model (grant mechanics: CLAUDE.md "Sentinel-grant mechanism"). It stays non-empty because a command whose body is empty fails the API call with a 400.)
